# Quem cai — Brasileirão 2026

Simulador da briga contra o rebaixamento entre Internacional, Grêmio, Vasco e Mirassol.

## Arquivos

- `index.html` — o app. Não precisa mexer.
- `resultados.js` — **o único arquivo que você edita.** Um jogo por linha:
  `rodada,mandante,visitante,gols,gols`. Salvou, o jogo trava no app para todo mundo.
- `escudos/` — os distintivos, um PNG por time: `INT.png`, `GRE.png`, `VAS.png`, `MIR.png`,
  `BOT.png`, `CTB.png`, `PAL.png`, `COR.png`, `CRU.png`, `FLA.png`, `FLU.png`, `BAH.png`,
  `CAP.png`, `CAM.png`, `RBB.png`, `SAN.png`, `SAO.png`, `VIT.png`, `REM.png`, `CHA.png`.
  Sem os arquivos, o app desenha um escudo com as cores da camisa.

## Atualizar um jogo

Abra `resultados.js` no GitHub, clique no lápis, acrescente a linha, escreva a mensagem do
commit e salve. Em um ou dois minutos o site novo está no ar.

## Base

A classificação embutida vai até a 27ª rodada (17/09/2026). Lance em `resultados.js` só os
jogos da 28ª em diante, mais Chapecoense x Vasco da 21ª.
